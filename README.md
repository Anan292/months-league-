# دوري الأشهر — Month League

PWA football league simulator: 12 month-named teams, 288 players, 22 rounds.

## GitHub Pages
1. Create a GitHub repository and name it e.g. `month-league`.
2. Upload all files in this folder to the repository's `main` branch.
3. In **Settings → Pages**, set **Source** to **GitHub Actions**.
4. The included workflow deploys automatically on every push to `main`.
5. Your site will be available at `https://YOUR-USERNAME.github.io/month-league/`.

## Netlify
- Import the GitHub repository in Netlify and publish the repository root, or
- Drag this folder to Netlify Drop.

No build command is required; this is a static PWA.
